## Nombre

Veranum Desktop

## Instalacion

El proyecto fue desarrollado con .NET Framework por lo tanto para correct el proyecto de la mejor manera debemos instalar el IDE [Visual studio](https://visualstudio.microsoft.com/es/) 2019 o 2022

## Uso

Una vez instalador el IDE, debemos configurar el editor para que inicie utilizando el proyecto **Desktop.Presentation**, para esto hacemos click derecho en el nombre del proyecto del menu de opciones seleccionamos el que dice **Establecer como proyecto de inicio**.

Una vez hecho esto le damos a `Iniciar` o apretamos `F5` y la aplicacion deberia iniciar.

## Consideracion

1. Este projecto consume directamente la API de la carpeta **server** creada con node, para poder ejecutar este proyecto es necesario ejecutar el servidor primero
